# IfesEssayBr

A unified repository of Python tools for automated essay evaluation developed at **IFES Campus Serra**. The project brings together modules for lexical diversity and complexity, linguistic metric calculation, synthetic text generation via LLMs, and topic alignment analysis for Natural Language Processing (NLP) research.

---

## 🛠️ Installation and Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ifesserraessaybr/IfesEssayBr.git](https://github.com/ifesserraessaybr/IfesEssayBr.git)
   cd IfesEssayBr
   ```

2. **Create a virtual environment and install dependencies:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Configure environment variables:**
   Create a `.env` file in the root directory of the project and fill in your API keys (such as `GEMINI_API_KEY` and `HF_TOKEN`).

## ⚙️ Configuration File (`config.json`)

Located in the repository root, the [`config.json`](config.json) file centralizes input/output directory paths and experiment hyperparameters, eliminating the need to manually edit paths inside the source code.

### Available Parameters

| Related Script | Key in `config.json` | Description |
| :--- | :--- | :--- |
| [`generate_mistral_essays.py`](src/TopicAlignment/Strategy1/generate_mistral_essays.py) | `"generate_mistral_essays - in"` | Input directory containing original JSON files for generation. |
| [`generate_mistral_essays.py`](src/TopicAlignment/Strategy1/generate_mistral_essays.py) | `"generate_mistral_essays - out"` | Destination directory for generated synthetic essays. |
| [`generate_mistral_alignment.py`](src/TopicAlignment/Strategy1/generate_mistral_alignment.py) | `"generate_mistral_alignment - in"` | Input directory containing the synthetic essays. |
| [`generate_mistral_alignment.py`](src/TopicAlignment/Strategy1/generate_mistral_alignment.py) | `"generate_mistral_alignment - out"` | Destination directory to save the generated alignments. |
| [`generate_mistral_metrics.py`](src/TopicAlignment/Strategy1/generate_mistral_metrics.py) | `"generate_mistral_metrics - grounded"` | Reference directory containing the original human essays (ground truth). |
| [`generate_mistral_metrics.py`](src/TopicAlignment/Strategy1/generate_mistral_metrics.py) | `"generate_mistral_metrics - synthetic_essays"` | Directory containing the synthetic essays to be evaluated. |
| [`generate_mistral_metrics.py`](src/TopicAlignment/Strategy1/generate_mistral_metrics.py) | `"generate_mistral_metrics - results"` | Output directory for statistical reports and metrics. |
| [`inspect_dataset.py`](src/TopicAlignment/json_dataset/inspect_dataset.py) | `"inspect_dataset - in"` | Directory containing the dataset JSON files to be inspected. |
| [`inspect_dataset.py`](src/TopicAlignment/json_dataset/inspect_dataset.py) | `"inspect_dataset - out"` | Full path to the output `.txt` audit report file. |
| [`inspect_dataset.py`](src/TopicAlignment/json_dataset/inspect_dataset.py) | `"inspect_dataset - total files"` | Number of files analyzed in the random sample. |
| [`inspect_dataset.py`](src/TopicAlignment/json_dataset/inspect_dataset.py) | `"inspect_dataset - seed"` | Random seed to ensure reproducibility during sampling. |

#### Example `config.json` structure:
```json
{
    "generate_mistral_alignment - in": "dataset/TopicAlignment/Strategy1/synthetic_essays/mistral_essays",
    "generate_mistral_alignment - out": "dataset/TopicAlignment/Strategy1/mapping/mistral_mapping",

    "generate_mistral_metrics - synthetic_essays": "dataset/TopicAlignment/Strategy1/synthetic_essays/mistral_essays",
    "generate_mistral_metrics - results": "dataset/TopicAlignment/Strategy1/results/mistral_evaluations",

    "inspect_dataset - in": "dataset/TopicAlignment/json_dataset/QwenOneshot",

}
```
