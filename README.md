# IfesEssayBr
Unified repository of Python tools for automated essay scoring and evaluation at IFES Campus Serra. It includes modules for lexical diversity and complexity, processing of linguistic metrics, and dataset analysis featuring ChatGPT texts and the complete base for NLP studies.

## 💾 Project Datasets

Due to file sizes, the project datasets are hosted on Google Drive and divided by processing stage.

> 📝 **Note:** The original essay dataset was provided in `.xml` format. To enable processing pipelines and input into Large Language Models (LLMs), the data was converted and structured into `.json` format (available in items 4 to 7 below).
