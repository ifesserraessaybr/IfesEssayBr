# Um Framework de Avaliação Automática para Redações em Português

Nesta primeira versão, o framework é composto pelos seguintes recursos: conjunto de dados (dataset), lista de marcadores discursivos e lista de léxico enviesado (*biased lexicon*).

## Conjunto de Dados (Dataset)

O conjunto de dados é composto por 1.840 redações distribuídas entre 95 temas. As redações foram coletadas do Banco de Redações do portal [UOL Educação](https://educacao.uol.com.br/bancoderedacoes). A cada mês, o UOL Educação divulga um tema, e os estudantes podem enviar por e-mail uma redação relacionada à proposta. Em seguida, um avaliador humano anônimo corrige aproximadamente 20 redações para publicação. As redações são avaliadas de acordo com as cinco competências do Exame Nacional do Ensino Médio (ENEM), exame realizado anualmente por milhões de estudantes brasileiros do ensino médio. O manual oficial do avaliador pode ser encontrado no seguinte [link](http://download.inep.gov.br/educacao_basica/enem/guia_participante/2018/manual_de_redacao_do_enem_2018.pdf).

O arquivo compactado do dataset contém 95 diretórios, cada um nomeado de acordo com seu respectivo tema. Cada diretório contém dois subdiretórios e dois arquivos. Os dois subdiretórios armazenam as redações: um contém a versão em XML das redações e o outro contém a versão em HTML. Os dois arquivos correspondem às versões em HTML e XML da proposta de redação (comando temático) sobre o tema divulgado. Há outro arquivo README dentro do pacote compactado que detalha a estrutura XML das redações e das propostas.

Por favor, reporte qualquer problema encontrado no conjunto de dados.

## Lista de Marcadores Discursivos

Marcadores discursivos são unidades linguísticas que estabelecem conexões entre sentenças para construir um discurso coeso e articulado. Para compor esse recurso, reunimos uma lista utilizando uma gramática da língua portuguesa [1] que elenca os principais conectores empregados para essa finalidade.
